# Local Secretary

## Register
Product: a personal Korean voice assistant running on the user's Mac.

## Purpose and users
The owner wants to speak to a local LLM and hear responses from Supertone/supertonic-2. The confirmed scope is one working conversation screen with microphone controls, transcript, text input and expandable local model settings. The primary outcome is hands-free turn-taking after starting the microphone, with an explicit way to interrupt playback.

## Principles
Keep conversation and current listening/thinking/speaking state easy to understand. Show actionable connection errors. Use local inference and no external fonts or analytics. Keyboard access, visible focus and readable Korean text are required. Avoid decorative dashboards and nested cards. Conversation lasts in browser memory only.
